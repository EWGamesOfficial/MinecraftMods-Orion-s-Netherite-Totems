# 🗿 Orion's Netherite Totems

Welcome to **Orion's Netherite Totems**, a custom Minecraft Java Edition resource pack created by **OrionTheDriftr** that modernizes, re-imagines, and customizes textures for version 1.21+!

---

## ✨ Key Features

* 🛡️ **The Netherite Totem:** Replaces the classic golden Totem of Undying with a sleek, dark Netherite metallic sprite featuring glowing soul-charged, diamond-blue eyes.
* 🖼️ **Secret Painting Discoveries:** Features updated, retro-inspired pixel art canvases with a deep nostalgic vibe (including hidden nods to classic adventure games and *Undertale* aesthetic styles).
* ⚙️ **Custom Client Main Menu:** Includes a fully customized, hilarious main menu background showcasing spinning 3D Netherite ingots and a custom splash text overlay!

---

## 📂 Repository File Layout

To install or explore this pack manually, the root directory requires the following file structure:
* `assets/` • Core folder containing the custom models, text formatting, and item textures.
* `pack.mcmeta` • System file holding metadata code and the custom main menu sub-descriptions.
* `pack.png` • The official square resource pack display icon shown in-game.
